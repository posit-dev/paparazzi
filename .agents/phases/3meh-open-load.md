## Mechanism decision (before code)

`pz_open()` creates a new session whose outgoing `about:blank` document can already report `readyState = "complete"` when `Page.navigate` returns. For the new-session `wait = "load"` path, register `Page.frameNavigated(wait_ = FALSE)` before `Page.navigate`, as the Shiny branch already does. After the existing `errorText` check, await the returned destination commit with the existing `nav_await(page, navigated, what = "page navigation")` only when `nav$loaderId` exists, then call `wait_for_load()` and retain `device_css_reapply()`. Share the single registration and conditional await between load and Shiny; leave `wait = "none"` and the wrapped-session branch unchanged. Fragment/same-document navigations without a loaderId must not wait for an event that will never arrive; navigation errors must still fail before awaiting. No timer, queue, extra flag, or init/restore-window edit.

## Mechanism amendment: listener lifetime (signed off before follow-up code)

The shared `wait_ = FALSE` event promise above has no cancellation: on a fresh `about:blank#fragment` navigation, CDP supplies no `loaderId` and emits no `frameNavigated`, so closing the page rejects that unused promise as an unhandled error. For the resolved `wait = "load"` mode only (including non-app `"auto"`), use the public Chromote 0.5.1 `Page$frameNavigated(callback_ = ...)` registration before `Page.navigate`. It returns a deregistration function. Resolve a `promises::promise` from its callback and pass that promise to the existing `nav_await` only when `loaderId` exists. Defer deregistration on `pz_open()` exit, including errorText, no loaderId, and thrown errors. Do not change the original Shiny `wait_ = FALSE` registration/await path, `R/nav.R`, or init/restore. No timer, queue, ordering flag, or extra guard. The callback may receive more than one event before exit; resolving an already-resolved promise is harmless.

Add a direct real-browser `pz_with_page("about:blank#fragment", ..., wait = "load")` regression and pump the child loop after closing to check there is no unhandled promise error. Keep the existing slow destination and navigation-error tests; run targeted `btw pkg test -f 'open|nav'` only. This amendment supersedes the shared-registration decision above solely for load waits.
