## Mechanism decisions

- `R/annotate.R` exports `pz_annotate(ctx, target = NULL, ..., type = "box", label = NULL, pad = NULL, reveal = NULL, id = NULL, color = NULL, font_family = NULL, font_size = NULL)` and `pz_annotate_clear(ctx, id = NULL, ...)`, both returning `ctx` invisibly. Only `type = "box"`, `reveal = "fade"/"none"` (`NULL` defaults to fade). `target = NULL` means the pinned current scope or root `document.body` as in existing resolution. A badge with `label = TRUE` numbers matches 1..n; a scalar string/number repeats on every match. Richer placement belongs to mkns. `pad` is scalar or four-sided CSS px (`NULL` means 0). Validate with existing checkers/cli. User ids are nonempty strings excluding reserved `"spotlight"` and `"caption"` (clear accepts both for future types); an omitted id generates an opaque page-side auto id.
- The page-side `Map<id, {elements, nodes, reveal, ...}>` attached to the annotation layer is the **only** annotation registry. No R-side list of ids, locators, styles, geometry or rendered markup. `loc_resolve(ctx, target, multiple = "all")` resolves once in current scope and auto-waits, then `Runtime.callFunctionOn` on the remote array passes actual `Element` references to the JS runtime; release the remote array afterwards. One id groups all matches; reuse replaces the entire group. Do not retarget an attached element after ordinary DOM replacement: a disconnected element hides until explicitly reannotated.
- Under the existing `#paparazzi-overlay-root` open shadow root, create one fixed `.pz-annotations` layer, pointer-events-none and aria-hidden, with one outline and optional badge per match. Explicit stacking puts it **below** `.pz-cursor`; inspect outlines stay separate. Use `textContent` and style properties for input, never user-supplied innerHTML. Counter-zoom against computed `<html>` zoom like the cursor so `getBoundingClientRect()` matches fixed viewport coordinates. `R/resolve.R` already excludes the host, and shadow descendants are invisible to the page's selector engine; `pz_find()` and element unions never include annotation nodes. `overlay_hide()` continues hiding only `.pz-inspect`, so stills capture annotations but not inspect outlines.
- The page-side `sync()` reads connected elements' `getBoundingClientRect()`, applies padding, and updates fixed box geometry; disconnected elements hide box and badge. Sync immediately on draw/replacement, then run one `requestAnimationFrame(sync)` chain while the Map is nonempty; stop on clearing its last entry. This only mirrors layout before paint and orders nothing relative to R/capture, the approved exception to the timer tripwire. `screenshot_capture()` also calls `sync()` immediately before `Page.captureScreenshot` so stills after synchronous layout changes are correct (including `pz_inspect(show = "screenshot")`); the call is a no-op if the overlay/layer is absent or empty.
- Fade uses WAAPI opacity over about 250 ms, reversed on clear; `none` is instant both ways. Draw, replacement and clear pump through their animations with existing `pump_loop(page$child_loop, duration)` **only when `stage_recording(page)` and not `page_recorder(page)$paused`**. Paused recordings, like no recording, apply final state instantly. Finish removal on page-side animation completion; after pumping, finalize removals synchronously if callbacks have not fired, so clear-all stops the follow loop. Do not introduce a timer, queue, R ordering flag, or blocking JS promise.
- Navigation destroys the old document and **all** its annotations. Register a fixed `Page.addScriptToEvaluateOnNewDocument` boot once (cursor pattern, DOM readiness handling) to re-inject only an *empty* layer and JS runtime; `pz_annotate()` and `pz_annotate_clear()` work on the new page. No locator recipes/rebinding or scope-vs-root distinction. bfcache restoration restores the old document and its live Map naturally. Document in `pz_annotate()` roxygen: annotations belong to the current document; navigating away removes them. The orchestrator owns the rebinding backlog issue.
- `R/stage.R` adds `annotate_color` (CSS color string), `annotate_font_family` (CSS font-family string), `annotate_font_size` (positive CSS px) with explicit `NULL` reset and built-in defaults; NULL style arguments use stage values at call time, and font properties style the badge. Change `R/screenshot.R` only for immediate sync; avoid `R/record.R` (concurrently owned). Generate `man/` and `NAMESPACE` with `btw pkg document`; add to `_pkgdown.yml` reference index if explicit.
