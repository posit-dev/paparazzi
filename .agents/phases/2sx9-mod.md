# `pz_press()` Mod modifier (paparazzi#2sx9)

Requirements: kata `2sx9`, `.agents/SPEC.md` § Camera, annotations, and captions; `1a3m` Mod decision. `Mod+K` means Meta when the page reports a Mac platform, Control otherwise. This task does not implement keystroke callouts.

## Mechanism (awaiting orchestrator sign-off)

- In `R/keys.R`, accept case-insensitive `Mod` in the existing modifier parser. Resolve it to `Meta` or `Control` **before** building the parsed modifier set and CDP events; reuse existing bitmasks, key table and `key_events()`. Add a `mod` resolution argument to `key_parse()` (required only for specs containing Mod). After resolution, reject duplicate physical modifiers, including `Mod+Meta` on Mac and `Mod+Control` elsewhere. A bare `Mod` is not a key (the key table remains unchanged).
- In `R/actions.R`, `pz_press()` detects the platform in page JS for specs containing Mod, once per call (not cached across navigations or pages): prefer nonempty `navigator.userAgentData?.platform`, fall back to `navigator.platform`; a case-insensitive `Mac` prefix indicates Meta, everything else Control. No platform lookup for ordinary key specs. Pass the resolved name into `key_parse()`; no changes to staging, recording, overlays, or device emulation. Document Mod in its roxygen, then regenerate `man/pz_press.Rd` with `btw pkg document`.
- In `tests/testthat/test-keys.R`, red-first parser cases cover both resolutions, case-insensitivity, combined modifiers and duplicate physical modifiers. In `test-actions.R`, real-Chrome tests override the browser platform for both Mac and non-Mac and capture `keydown` on `K` to assert `metaKey`/`ctrlKey` (not only CDP argument lists); confirm explicit Meta/Control remain literal. Mock both reported platform APIs where present, and test fallback when `userAgentData.platform` is absent or empty. Prefer `Emulation.setUserAgentOverride(platform = ...)` on the existing test page if it reliably changes both APIs; otherwise inject the mocked properties on new document and navigate the fixture. Restore overrides or use a fresh locally closed page per case. Tests must fail without the feature.

Gates: start with `.agents/chrome-lock.sh btw pkg test -f 'keys|actions' --reporter minimal` before feature work; record the red test run, then repeat the same targeted filters green. Run `air format --check .` and `jarl check .`. Stop and consult if this requires a timer, queue, extra ordering flag, guard-for-guard, or changes to the init/restore window. Open question for sign-off: should contradictory `Mod+Control`/`Mod+Meta` specs be rejected after platform resolution as above?
