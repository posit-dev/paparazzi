# Attached-annotation frame boxes (0rdt) (signed off by orchestrator)

Requirements: kata 0rdt; `.agents/SPEC.md` § Framing and § Camera, annotations, and captions (Annotations / Frames); kata 1a3m decision 4 and the `target_box` naming decision. This phase changes measurement, not annotation lifetime, painting, or the encoder.

## Mechanism decisions

- Add `target_box = c("element", "annotated")` to `pz_frame()` and `target_box = NULL` to `pz_stage_frame()` (NULL selects the `pz_frame()` default). Normalize via `arg_match()` in `new_frame_spec()`; store one `target_box` string in the existing frame spec and show it in `print.paparazzi_frame()`. A staged frame keeps its usual lazy target; `frame =` still replaces it wholesale. Document that `bounds` stays element-only and the viewport fallback does not include unattached annotations.
- In `R/annotate.R`, give the existing `.pz-annotations.pz` object **one** read-only entry point, `paintedRects(elements)`. It calls `sync()` synchronously, then returns the union of viewport-coordinate painted rectangles for Map entries whose individual `entry.elements[i]` equals or descends from at least one supplied target (`target.contains(el)`). Only include the matching index within a multi-match entry. Skip disconnected/hidden annotation nodes and all redactions; mark geometry is shape plus badge, callout geometry bubble plus arrow line/head plus badge (not just the bubble container), and spotlight geometry is the *visible padded hole* `entry.holes[i]`, not the giant dimming SVG. Read actual positioned DOM/SVG geometry after sync, including overflow and arrow geometry, rather than recomputing the bubble layout from the target. For SVG strokes, account for their painted stroke width around the measured path/line, including zero-width vertical/horizontal lines; skip hidden paths such as an arrow suppressed on overlap. The spotlight's mask-hole geometry must be translated from its SVG bounds into viewport coordinates if Chrome's `getBoundingClientRect()` for a mask child does not expose that placement. Return `null` for no matching painted nodes. Exiting/cleared nodes are outside the Map and must not contribute. The element's own box remains R's existing `el_rects()` value. Do not boot a layer merely to query an unannotated page: a missing layer returns no extra rect.
- In `R/frame.R`, add a small `frame_target_box(ctx, els, spec, call)` used by both the resolved-target and pinned-scope branches of `frame_content_box()`: union `el_rects(els)` and, only for `annotated`, the layer query using the **same resolved element references** (`els_call()` / `Runtime.callFunctionOn` on the element array; no re-resolution or R-side annotation registry). Convert the returned four-edge JS union into a four-edge R box and union it with the element box before `pad`, `offset`, `ratio`, and bounds; keep `frame_measure()`'s page/viewport clamps and rounding intact. Handle a null JS answer as element-only. Camera can reuse this helper with a `new_frame_spec(target_box = ...)`.
- In `R/camera.R`, keep `target` as an element target, not a full `pz_frame()` (camera must still own zoom/pad and home ratio/bounds). Add `target_box = c("element", "annotated")` to `pz_camera()` after its existing controls, validate with `arg_match()`, and default to `"element"` regardless of `pz_stage_frame()`. Staged framing affects stills but never camera shots; callers opt in explicitly. Measure before existing camera padding and viewport-to-page translation; `rec$camera[[i]]$box` thus records the enlarged shot. Camera remains a no-op outside recording. `pz_camera_reset()` and follow-the-action remain unchanged.
- In `R/record.R`, reject an **explicit** `frame = pz_frame(target_box = "annotated")` at `pz_record_start()`, before creating a recorder or measuring a `when = "start"` crop, with an actionable `cli::cli_abort()` suggesting an element-only home. A staged annotated frame used as the recording default instead has `target_box` treated as `"element"` silently: create an element-only copy for the recorder, without mutating the staged still frame. This works with both `when = "start"` and `"stop"`. Home measurement remains element-only. Explain the explicit/staged distinction in both `pz_stage_frame()` and `pz_record_start()` roxygen; regenerate `man/` with `btw pkg document`.

## Red-first tests and gates

- `tests/testthat/test-frame.R`: construct a fixed small target with a callout bubble outside it; compare the exact frame measurement/PNG dimensions for `"element"` and `"annotated"` using zero pad and fixed side. Check descendant attachment and multi-target union, an unrelated/unattached callout excluded, and no-layer/default behavior. Verify a spotlight's padded *hole*, not its viewport-sized scrim, expands an attached target; redaction (including padded fill) contributes nothing. Test after a synchronous target shift so the query must sync before measuring. Stage a frame with `target_box = "annotated"` and verify an implicit still frame; check invalid values and printed spec.
- `tests/testthat/test-camera.R`: start a recording with an ordinary home frame; draw a callout outside the shot target, then compare `rec$camera[[i]]$box` for the default/explicit `"element"` and explicit `"annotated"`, even when staged framing is annotated, with `pad = 0`, `duration = 0`, and `camera_follow = FALSE`. Avoid encode/pixel sampling here.
- `tests/testthat/test-record.R`: assert explicit annotated home frames fail before a recorder exists, for `when = "start"` and `"stop"`; staged annotated frames record successfully with element-only home boxes at start and stop (and leave the staged spec unchanged). Record focused red results before implementation. Run `.agents/chrome-lock.sh btw pkg test -f 'frame|camera|record|annotate|screenshot|stage' --reporter minimal` (split into focused then seam runs if needed); judge FAIL/WARN/SKIP/PASS. `btw pkg document`, `air format --check .`, `jarl check .`, `git diff --check` afterwards. Keep Chrome to a few minutes with shared lightweight page fixtures, short/zero camera moves, and no encode where not needed.

## Escalation

- Stop for init/restore or device-emulation edits; timers, queues, extra ordering flags, stored image/display state, or guards for guards. No new capture synchronization: the layer's synchronous `sync()` is the only ordering requirement.
- Orchestrator sign-off: camera defaults to element and never inherits staged framing; only explicit annotated home framing errors, while staged annotated home framing silently uses element geometry.
