# paparazzi: Scripted Demo Videos, Screenshots, and Tests for Web Pages

Script polished demo videos and screenshots of anything that runs in a
web browser, including 'Shiny' apps, 'Quarto' documents, and live
websites. A pipeable interface built on 'chromote' clicks, types, and
waits the way a person would. While recording, a cursor glides between
elements, text is typed one character at a time, and a camera zooms and
pans to the action. Annotations, callouts, spotlights, captions, and
redactions follow their elements as the page changes. Frame captures to
an element or aspect ratio, emulate phones, dark mode, and other
devices, and write MP4, WebM, or GIF files. Without a recording, the
same scripts run at full speed as browser tests with auto-waiting
actions and retrying expectations that work with 'testthat'.
